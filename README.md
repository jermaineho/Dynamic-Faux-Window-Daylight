# Dynamic Faux Window: Daylight Live Wallpaper

As an amateur landscape photographer, I always wanted a way to display my favorite views on screen—like looking out a window at a breathtaking scenery. Now, with the power of AI, I can finally make that a reality.

---

## ✨ Features
* **AI Depth Estimation**: Uses AI depth models to create realistic 3D parallax and depth-aware lighting.
* **Dynamic Cloud Layers**: Multi-layer procedural cloud system with customizable flow, wind, and density.
* **Interactive Lighting & Shadows**: Real-time cloud shadow projection and customizable sun rays/flicker effects.
* **Window Frame Integration**: Supports custom foreground frames with automated color sampling and exposure response.

## 📦 Installation
This project is packaged as a **Lively Wallpaper** scene. No complex installation required!

1. Download and install [Lively Wallpaper](https://github.com/lively-community/lively).
2. [Download](https://github.com/jermaineho/Dynamic-Faux-Window-Daylight/releases/) the `EN version ZIP` from the releases.
3. Simply **drag and drop** the downloaded ZIP file directly into the Lively Wallpaper window.
4. Enjoy the new window to your favorite view!

# 動態日晝仿窗動態桌布

身為一位業餘風景攝影師，我一直希望能有一種方式，可以在螢幕上隨時展示我最愛的景色，透過窗戶望向令人屏息的壯麗風光。現在，藉由 AI 的力量，我終於能將這個夢想化為現實了！

---

## ✨ 功能特色
* **AI 深度估算**：利用 AI 深度模型創造逼真的 3D 視差與具備深度感知的打光效果。
* **動態雲層系統**：多層程序化雲霧，支援自定義流動方向、風切與稠密度。
* **互動光影與陰影**：即時雲層背景投影陰影，以及可自定義的太陽光芒與閃爍效果。
* **窗框完美融合**：支援自定義前景框，具備自動取樣背景色與曝光連動反應。
